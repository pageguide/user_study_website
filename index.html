You will read a question, inspect the answer a web agent gave, and decide whether that answer is correct. Some answers are correct and some are not.

  • Yes/No judgment
  • 3 min per claim

What you will do

  1. 1
    Read the question and the agent’s answer. The saved webpage, or the run the agent recorded, appears beside them.
  2. 2
    Answer Yes or No. Decide whether the agent’s answer correctly answers the question.
  3. 3
    Point to the supporting evidence. Select the passage or image that helped you judge the claim.
