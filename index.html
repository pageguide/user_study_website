🎓 PageGuide User Study

You will review a series of tasks completed by a web agent. For each task, you will see what the agent did and the answer it gave. Then you will decide whether the agent got it right and where it went wrong if there was a problem.

There are no trick questions. This study is not testing you. We are studying how easy or hard it is to check an agent's work. If you cannot tell what happened, choose that option. Please answer from what you can actually see.
